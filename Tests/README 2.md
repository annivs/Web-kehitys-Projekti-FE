# Ohjelmistotestaus - yksilötehtävät

## Tehtävä 1. 
Tässä tehtävässä piti ladata Robot Framework ja siihen vaadittavat kirjastot:
- Robot Framework
- Browser Library
- Requests library
- CryptoLibrary
- Robotidy

** Koodit latauksia varten terminaalissa **

Robot Framework:

````
pip3 install robotframework
````
Kirjastot latasin Github- linkeillä:

Robotidy:

````
pip3 install git+https://github.com/MarketSquare/robotframework-tidy.git
````

Browser library: 

````
pip3 install git+https://github.com/robotframework/robotframework-browser.git
```
Requests library:

````
pip3 install git+https://github.com/robotframework/robotframework-requests.git
````

Cryptolibrary:

````
pip3 install git+https://github.com/robotframework/robotframework-crypto.git
````
Tällä komennolla pystyy tarkistamaan onko kaikki kirjastot ladattu:

````
pip3 list | grep "robotframework"
````
